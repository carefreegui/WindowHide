## A 组 · 现在就能做(约 10 分钟,验上次事故的修复)

> 前提:重启工具(`run.bat`),关闭所有"已隐藏"状态。

### [ ] A1 普通权限下点隐藏永劫无间 —— 应该"拒绝动手"

1. **不要**提权,正常双击 `run.bat`
2. 打开永劫无间(全屏进游戏)
3. 工具列表里勾选它 → 点「隐藏勾选」

**预期**:弹出气泡「永劫无间 以管理员权限运行,本工具没有权限操作它,
请用托盘菜单的「以管理员身份重启」后再隐藏」,**游戏画面不能有任何变化**
(不能被最小化、不能卡)。

> 这一条是关键:旧版本会把它最小化然后回不来。现在的行为必须是"什么都不做"。

### [ ] A2 托盘「以管理员身份重启」

1. 托盘图标右键 → 点「以管理员身份重启」
2. 系统弹 UAC → 点"是"

**预期**:旧图标消失、新图标出现(图标应该是普通状态,不是"已隐藏"),
主界面能打开,任务管理器里 python 进程的"以管理员身份运行"应为"是"。

**失败时给我**:卡在 UAC 不动?新实例没起来?两个托盘图标同时存在?

### [ ] A3 管理员权限下隐藏全屏永劫无间

1. 确保工具已经是管理员身份(A2 做完就是)
2. 进游戏(全屏),工具里勾选 → 「隐藏勾选」

**预期**:游戏画面消失、声音也停(如果开了"隐藏时静音")、任务栏没有游戏按钮、
Alt+Tab 里也没有。**不应**停在"最小化到桌面"。

### [ ] A4 恢复(A3 之后)

1. 按全局快捷键(默认 `Ctrl+Alt+H`)或托盘图标单击
2. 或主界面点「恢复」

**预期**:游戏窗口回来并且是前台全屏状态;声音恢复。

**失败时给我**:是"窗口回来了但不是全屏"、还是"完全没反应"、还是"工具界面卡住"。

### [ ] A5 万一卡住 —— 急救脚本

1. 如果 A3/A4 之后游戏卡在最小化、任务栏也找不到
2. 双击 `tools/rescue_window.bat` → UAC 点"是"

**预期**:脚本打印一串状态,最后 `已恢复`,游戏回到屏幕。
**失败时给我**:脚本窗口里的全部输出(截图就行)。

## C 组 · 环境覆盖(有空再做,长期有效)

如果你有第二块屏,或者把系统缩放改成 100% / 125%:

- 125% 缩放下界面有没有错位、截图里的文字有没有糊

### [ ] C2 Windows 10(如果有另一台机器)

- 内存有没有明显增长(任务管理器看 python 进程)

### [ ] C4 开机自启

**预期**:登录后工具自动在托盘出现,不弹主界面,已保存的规则仍然记得。

### [ ] C5 托盘观感

## 出问题时给我什么

有这三样基本就能定位:

1. **日志**:`%APPDATA%\WindowHide\windowhide.log`(最后 50 行就够)
2. **程序名 + 当时状态**:比如"永劫无间,NARAKA 全屏,点隐藏后变成最小化"
3. **工具是不是管理员权限运行**(任务管理器 → 详细信息 → "以管理员身份运行"列)

如果界面卡住了,先别关,用任务管理器生成一份 python 进程的转储太麻烦 ——
直接截图 + 日志就行。
