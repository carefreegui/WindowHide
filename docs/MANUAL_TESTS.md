## A 组 · 现在就能做(约 10 分钟,验上次事故的修复)

> 前提:重启工具(`run.bat`),关闭所有"已隐藏"状态。
> **注意行为变了**:默认不再"先最小化再隐藏",因为那招会把永劫无间搞得
> 回不来。所以 A3 的预期是"**报没藏掉**",不再假装成功。

### [ ] A0 最省事的解法:把游戏设成"无边框窗口"

永劫无间(以及绝大多数游戏)的显示设置里有 **「无边框窗口 / 窗口化全屏」**
这一档。换成它之后,游戏不再是独占全屏,本工具的普通隐藏就能 100% 生效、
也不会卡死游戏。**先试这个**,不行再看下面。

### [ ] A1 普通权限下隐藏永劫无间 —— 应该"拒绝动手"

1. **不要**提权,正常双击 `run.bat`
2. 打开永劫无间(全屏进游戏)
3. 勾选它 → 点「隐藏勾选」

**预期**:弹气泡「…以管理员权限运行,本工具没有权限操作它…」,
**游戏画面不能有任何变化**(不能被最小化、不能卡)。

### [ ] A2 托盘「以管理员身份重启」

1. 托盘图标右键 → 「以管理员身份重启」→ UAC 点"是"

**预期**:旧图标消失、新图标出现,主界面能打开,只有一个托盘图标。

### [ ] A3 管理员权限下隐藏全屏永劫无间(默认设置)

1. 确保工具已是管理员身份
2. 进游戏(独占全屏),勾选 → 「隐藏勾选」

**预期**:弹气泡「…有 1 个窗口没藏掉(已还原到原样),通常是它以独占全屏
渲染…」。**游戏画面应该完全不受影响** —— 不卡、不黑屏、能继续玩。
界面本身必须保持响应(不出现"未响应")。

> 这一条是这次修复的核心:**宁可不藏,也不把你游戏搞死**。

### [ ] A4(可选,有风险)强制隐藏

设置 → 行为 → 勾「强制隐藏独占全屏游戏」→ 再按 A3 做一次。

**预期**:游戏画面消失、任务栏/Alt+Tab 里没有它。**但游戏很可能就此卡死**
(主线程不再处理消息),恢复按钮按下去也不会回来。

**如果卡死**:看 A5。这条只是为了确认"强制"确实会藏住,代价你自己权衡。

### [ ] A5 急救脚本

1. 对刚才卡住的窗口双击 `tools/rescue_window.bat` → UAC 点"是"

**预期**(修好后的版本,2 秒内跑完):
- 正常情况:打印 `已恢复`
- 目标已卡死:打印 `⚠ 目标窗口当前无响应…` 和
  `没救回来…hung=True 表示它主线程已经不理消息了…只能结束进程重开`

**两种结果都算通过** —— 重点是不能卡住、不能假装成功。
**失败时给我**:脚本窗口的完整输出(截图)。

## B 组 · 现在也能做(场景 / 保护名单 / 性能)

> 这三条是新功能,自动化测试覆盖了逻辑(20 条断言),但"用起来顺不顺"只有你能判断。

### [ ] B0 场景:一次切换换一批窗口

1. 开两个程序(比如浏览器 + 微信)
2. 主界面勾浏览器 →「场景 ▾」→「新建场景…」,起名「摸鱼」
3. 勾微信 →「场景 ▾」→「新建场景…」,起名「上班」
4. 点「场景 ▾」→「摸鱼」→ 预期:浏览器被藏,**微信还在**

**预期**:切「上班」时浏览器自动回来、微信被藏;切场景时手动勾选的窗口
不会被放掉;没匹配到窗口时会弹气泡说明(不是没反应)。

**失败时给我**:是"藏了不该藏的"、还是"该藏的没藏"、还是"弹出什么奇怪提示"。

### [ ] B0b 永久化:重启工具后场景还在

1. 做完 B0 后,托盘右键「退出」
2. 重新 `run.bat`

**预期**:状态栏显示「场景「上班」」,点场景菜单看到刚才两个场景都在;
之前藏着的窗口依然是隐藏状态(工具重启会重新接管)。

### [ ] B0c 保护名单:该拒绝的必须拒绝

1. 列表里找 `TextInputHost.exe`(Windows 输入体验)或 `dwm.exe`
2. 看它状态列是不是「受保护」,勾选框是否点不动
3. 在设置 →「行为」→「永不隐藏的进程」里填 `notepad.exe`,保存
4. 打开记事本,列表里它应该变成「受保护」且勾不动

**预期**:这类窗口永远藏不掉,并且不会静默无反应。

### [ ] B1 无响应程序在场时界面不卡

1. 在项目目录起 3 个挂起探针:
   `for /l %i in (1,1,3) do start "" .venv\Scripts\pythonw.exe tests\hang_probe.py`
2. 打开工具主界面,观察列表是否每秒"顿"一下
3. 随便勾一个窗口点隐藏,感受按钮响应

**预期**:列表不顿(首轮之后就不再去问它们标题了)、按钮点了立刻有反应。
这类窗口的标题列会显示 `(无响应)`。

### [ ] B2 日志不会无限长

1. 正常用一两天后,看 `%APPDATA%\WindowHide\windowhide.log` 大小

**预期**:始终 ≤ 1 MB,并且能看到 `.log.1` / `.log.2` 之类的轮转文件。

---

### [ ] B3 规则持续生效(可选,默认关)

1. 设置 →「行为」→ 勾上「规则持续生效」,保存
2. 场景选「上班」(微信),确认微信被藏
3. 从托盘点「恢复」把微信放出来
4. 等 10 秒

**预期**:微信**不会**被自动藏回去(你手动恢复 = 你说了算);
但如果你关掉微信再重新打开,约 3 秒内它会自动被藏。

## C 组 · 环境覆盖(有空再做,长期有效)

### [ ] C1 多显示器 / 不同缩放

如果你有第二块屏,或者把系统缩放改成 100% / 125%:
- 全屏游戏藏在副屏上 → 能不能藏住、恢复后回到副屏
- 125% 缩放下界面有没有错位、截图里的文字有没有糊

### [ ] C2 Windows 10(如果有另一台机器)

Win10 的 DWM 行为和 Win11 有差异,重点验:全屏游戏隐藏/恢复、托盘气泡是否显示。

### [ ] C3 长时间挂机

挂 4~8 小时(期间正常用电脑),然后看:
- 内存有没有明显增长(任务管理器看 python 进程)
- 被隐藏的程序一直没被放出来吧?恢复还正常吧?

### [ ] C4 开机自启

设置 → 行为 → 勾「开机自动启动」→ 重启电脑

**预期**:登录后工具自动在托盘出现,不弹主界面,已保存的规则仍然记得。

### [ ] C5 托盘观感

右键托盘图标看菜单是否完整、气泡提示是否被系统"专注助手"吞掉
(Win11 通知设置里可以放行)。

## 出问题时给我什么

有这三样基本就能定位:

1. **日志**:`%APPDATA%\WindowHide\windowhide.log`(最后 50 行就够)
2. **程序名 + 当时状态**:比如"永劫无间,NARAKA 全屏,点隐藏后变成最小化"
3. **工具是不是管理员权限运行**(任务管理器 → 详细信息 → "以管理员身份运行"列)

如果界面卡住了,先别关,用任务管理器生成一份 python 进程的转储太麻烦 ——
直接截图 + 日志就行。
